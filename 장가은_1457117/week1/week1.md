## 📅 26.01.06 (화) — AI 핵심 모델 구조와 개발 환경 이해

이번 학습에서는 **대표적인 AI 모델 구조와 동작 원리**, 그리고  
실제 AI 개발을 위한 **개발 환경 세팅(가상환경)** 까지 함께 다뤘다.

단순히 모델 이름을 아는 수준을 넘어,  
**각 모델이 어떤 문제를 해결하기 위해 등장했는지**,  
**어떤 상황에서 사용되는지**를 중심으로 이해하는 데 집중했다.

---

### 1️⃣ CNN (Convolutional Neural Network)

CNN은 이미지 데이터를 처리하기 위해 고안된 **합성곱 신경망 구조**이다.

기존의 완전연결 신경망은 이미지처럼 고차원 데이터를 그대로 입력받을 경우  
파라미터 수가 급격히 증가하고, 공간적 특징을 학습하기 어렵다는 한계가 있다.

CNN은 이러한 문제를 해결하기 위해 다음과 같은 특징을 가진다.

- **Convolution(합성곱)** 연산을 통해 이미지의 국소적 특징(엣지, 패턴 등) 추출
- 필터(커널) 공유를 통한 파라미터 수 감소
- **Pooling**을 통해 중요한 특징만 유지하며 연산 효율 향상

이를 통해 CNN은 이미지 분류, 객체 인식, 얼굴 인식 등  
**시각 정보 처리 분야의 기본 모델**로 자리 잡았다.

이번 학습을 통해 CNN은 단순한 이미지 분류 모델이 아니라,  
**공간적 구조를 가진 데이터에 특화된 모델**이라는 점을 이해하게 되었다.

---

### 2️⃣ Transformer

Transformer는 기존 RNN, LSTM 계열 모델이 가지던  
**순차 처리의 한계와 긴 문맥 처리 문제**를 해결하기 위해 등장한 모델이다.

핵심 개념은 **Self-Attention 메커니즘**으로,  
문장 내 각 단어가 다른 모든 단어와의 관계를 동시에 고려해 중요도를 계산한다.

Transformer의 주요 특징은 다음과 같다.

- 입력 데이터를 **병렬 처리**하여 학습 속도가 빠름
- 긴 문장에서도 문맥 손실이 적음
- Attention 기반으로 단어 간 관계를 명확히 학습

이 구조는 이후 대규모 언어 모델(LLM)의 기반이 되었으며,  
자연어 처리뿐 아니라 이미지, 음성 등 다양한 분야로 확장되고 있다.

이번 학습을 통해  
“요즘 AI 모델의 중심에는 Transformer 구조가 있다”는 말을  
이론적으로 이해할 수 있었다.

---

### 3️⃣ Diffusion Model

Diffusion Model은 최근 주목받고 있는 **이미지 생성 모델**이다.

기본 아이디어는 다음과 같다.

- 원본 데이터에 **점진적으로 노이즈를 추가**
- 완전히 무작위 상태가 된 데이터를  
  **거꾸로 복원하는 과정을 학습**

즉, 모델은 **노이즈를 제거하는 방법 자체를 학습**하며,  
이를 통해 새로운 이미지를 생성한다.

Diffusion Model은 GAN 대비 학습이 안정적이고,  
고품질 이미지 생성이 가능하다는 장점이 있다.

이번 학습을 통해  
이미지 생성 AI가 한 번에 결과를 만드는 것이 아니라,  
**단계적으로 이미지를 복원한다는 점**이 인상 깊었다.

---

### 4️⃣ Miniforge 기반 Conda 가상환경 생성

모델 개념 학습과 함께, **AI 개발 환경 관리의 중요성**도 다뤘다.

가상환경을 사용하는 이유는 다음과 같다.

- 프로젝트별 라이브러리 **버전 충돌 방지**
- 실험 환경의 **재현성 확보**
- 팀 단위 협업 시 환경 통일

Miniforge는 불필요한 패키지를 최소화한 Conda 배포판으로,  
AI/머신러닝 환경 구성에 적합하다.

이번 학습을 통해  
**환경 관리 또한 AI 개발의 중요한 요소**임을 인식하게 되었다.

## 📅 26.01.07 (수) — 컴퓨터 비전 전체 파이프라인 이해

이번 수업에서는 이미지가 모델에 입력되고  
결과가 사용자에게 전달되기까지의 **전체 컴퓨터 비전 파이프라인**을 학습했다.

모델 구조뿐 아니라,  
**데이터 처리 방식이 성능에 얼마나 큰 영향을 미치는지**를 체감할 수 있었다.

---

### 1️⃣ 컴퓨터 비전 전처리 (Pre-processing)

#### 1.1 기하학적 변환 (Geometric Transformation)

- Resize, Crop
- Rotation, Flip
- Translation

입력 이미지의 크기·비율·위치를 조정하여  
모델이 다양한 입력에 안정적으로 대응하도록 돕는다.

---

#### 1.2 비율 유지 패딩 (Aspect Ratio 유지)

- 비율 유지 Resize
- 남는 영역 Padding 처리
- 객체 형태 왜곡 방지

특히 객체 탐지·분할 모델에서 중요한 전처리 전략임을 이해했다.

---

#### 1.3 데이터 증강 (Data Augmentation)

- 좌우 반전, 회전
- 밝기·대비 조절
- 랜덤 크롭, 노이즈 추가

한정된 데이터를 확장해  
모델의 일반화 성능을 높이는 핵심 전략이다.

---

### 2️⃣ 컴퓨터 비전 추론 (Inference)

#### 2.1 이미지 분할 (Image Segmentation)

- 분류: 이미지 전체 라벨
- 객체 탐지: 위치 + 클래스
- **이미지 분할**: 픽셀 단위 예측

정밀한 영역 인식이 필요한  
의료 영상, 자율주행 분야에서 중요하게 활용된다.

---

### 3️⃣ 컴퓨터 비전 후처리 (Post-processing)

- Confidence 기준 필터링
- 노이즈 제거
- 결과 시각화
- 다중 결과 정제

**모델 성능은 전처리 + 모델 + 후처리의 합**이라는 점을 명확히 이해했다.

---

## 📅 26.01.08 (목) — LLM 학습의 3단계 이해

LLM은 단순히 많은 데이터를 학습한 모델이 아니라,  
**3단계 학습 과정을 통해 사람과 자연스럽게 상호작용하도록 발전**한다.

---

### 1️⃣ 사전훈련 (Pre-training)

- 대규모 텍스트 데이터 학습
- 다음 단어 예측 방식
- 언어 구조와 패턴 학습

언어를 “말할 수는 있지만, 의도가 명확하지 않은 상태”의 모델을 만든다.

---

### 2️⃣ 지도 미세조정 (SFT)

- 질문–답변 데이터 기반 학습
- 지시를 따르는 응답 방식 학습

모델에게 **어떻게 대답해야 하는지**를 가르치는 단계이다.

---

### 3️⃣ 인간 피드백 기반 강화학습 (RLHF)

- 인간 선호도 평가
- 보상 모델 학습
- 강화학습 적용

모델이 **더 자연스럽고, 안전한 응답**을 생성하도록 조정한다.
