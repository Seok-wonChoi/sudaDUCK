## 0. 프로젝트 소개

마음 놀이터(Mind Playground)는 아이들이 실제 생활에서 자주 겪는  
**인사, 거절, 부탁, 감정 표현**과 같은 사회적 대화 상황을  
AI 아바타와의 **실시간 상호작용**을 통해 안전하게 연습할 수 있도록 설계된 학습 서비스이다.

아이들은 AI와 대화를 나누며 말투, 감정 표현, 반응 속도를 반복적으로 연습하고,  
서비스는 이 과정에서 발생하는 **음성 반응, 침묵 여부, 표정 변화** 등을 기반으로  
아이의 대화 특성을 분석한다.

- 아이에게는 **즉각적인 피드백 + 시각적 보상** 제공  
- 부모에게는 **사회적 말하기 과정과 변화 양상**을 간단한 리포트로 전달

본 프로젝트는 사회성을 성격이나 타고난 기질로만 보는 관점에서 벗어나  
**연습과 반복을 통해 학습 가능한 능력**으로 재정의한다.  
AI는 판단자가 아니라 **대화 연습을 돕는 코치** 역할을 수행한다.

## 1. 프로젝트 개요

### 1.1 배경 및 필요성

#### 기존의 문제점
- 유아(4~7세)는 **사회적 대화(인사, 거절, 감정 표현)**를 반복 연습해야 하지만,
  - 현실에서는 실수 → 혼남 / 관계 단절로 이어지기 쉬움
- 스마트폰은 이미 **디지털 네니(Digital Nanny)** 로 활용되지만,
  - 유튜브 등 **일방향 시청 중심**
  - 사회성·의사소통 능력 발달에 부정적 영향
- 부모는 아이의 사회성을
  - 감으로만 판단
  - 구체적으로 어떻게 지도해야 할지 어려움

#### 해결 방안
- 스마트폰을 **제한의 대상**이 아닌 **훈련 도구**로 전환
- AI 아바타와의 **실시간 쌍방향 상호작용**으로
  - 사회적 상황을 안전하게 반복 연습
- 아이의 말·표정·반응을 분석해
  - 즉각 피드백 제공
  - 부모에게 데이터 기반 리포트 제공

➡️ **사회성을 ‘성격’이 아닌 ‘훈련 가능한 기술’로 재정의**

---

### 1.2 목표 (Goals)

- [ ] WebRTC 기반 **실시간 영상 상호작용 환경** 구축
- [ ] 아이의 **음성·표정 반응 기반 AI 피드백 로직** 구현
- [ ] 사회적 상황 시나리오 기반 **대화 훈련 플로우** 완성
- [ ] 부모를 위한 **사회성 요약 리포트** 제공

## 2. 핵심 기능 (Key Features)

| 구분 | 기능 명칭 | 상세 설명 | 우선순위 |
|---|---|---|---|
| 통신 | 실시간 영상 상호작용 | WebRTC 기반 아이–AI 아바타 영상 통신 | P0 |
| 시나리오 | 사회성 상황 연습 | 거절·부탁·감정 표현 등 1~2개 상황 제공 | P0 |
| 분석 | 반응 분석 | 음성 크기, 침묵 시간, 표정 상태 분석 | P0 |
| 피드백 | 마음 온도계 UI | 긍/부정 반응에 따른 실시간 시각 피드백 | P0 |

| 리포트 | 부모 요약 리포트 | 아이의 반응 특성 + 대화 가이드 제공 | P1 |

## 3. 서비스 플로우 (User Workflow)

### 0) 진입 전제
- **부모 계정**이 메인(결제/설정/리포트)
- **아이 프로필**은 부모 아래 여러 개 생성 가능(형제/자매 고려)
- 사용 형태: **“부모가 시작 버튼 → 아이가 놀이 진행”**

---

### A. 온보딩/세팅 플로우 (첫 1회)

#### A-1. 앱/웹 접속 → “시작하기”
1. **랜딩 화면**
   - CTA: `시작하기` / `로그인`
   - “오늘 연습: 거절하기 / 부탁하기” 예시 노출
2. **권한 요청(필수)**
   - 카메라/마이크 권한 팝업
   - 미허용 시: “연습을 위해 카메라/마이크가 필요해요” 안내 후 재요청

#### A-2. 부모 계정 생성/로그인 (간단 버전)
1. **부모 로그인**
   - MVP: 이메일/비번 또는 소셜(선택)
2. **아이 프로필 생성**
   - 입력: 아이 닉네임(예: 지후), 나이(4~7), 말하기 수준(선택: `짧게/보통/많이`)
   - 저장 시 아이 프로필 카드 생성

#### A-3. 연습 목표 설정 (부모용)
1. **오늘 연습 항목 선택**
   - 선택지: `인사하기` `정중히 거절하기` `양보/부탁하기`
   - MVP는 1~2개만 활성화
2. **AI 친구(아바타) 선택**
   - 아이가 선택하는 이미지 카드 UI
   - 예: 포근이(강아지), 용용이(공룡)
   - 선택 즉시: “안녕! 나는 포근이야” 짧은 음성/텍스트 인사

---

### B. 오늘의 놀이 시작 플로우 (매일 반복)

#### B-1. 홈 → “놀이 시작”
1. 홈 화면에서 아이 프로필 카드 선택
   - `지후로 시작하기`
2. 오늘의 미션 확인 화면
   - “오늘은 **정중하게 거절하기** 연습할 거야!”
   - 예상 소요: 2~3분
   - 버튼: `시작!`

#### B-2. WebRTC 세션 진입 (Core)
1. “연결 중…” 화면
   - 카메라 프리뷰 + 마이크 테스트(막대 그래프)
   - 버튼: `연결하기`
   - 백엔드: 세션 룸 생성 / 시그널링 시작
2. 연결 성공 → “놀이 화면” 전환
   - 화면 구성(권장)
     - 왼쪽: 아이 영상
     - 오른쪽: AI 아바타(애니메이션/이미지)
     - 하단: **마음 온도계(0~100)** + 현재 상태 문구
     - 우측 하단: `마법의 단어` 버튼(수동 힌트)

---

### C. 상황극 진행 플로우 (턴 기반)

> ✅ 안정적인 구현을 위해 “턴(turn) 기반” 구조 사용  
> (한 턴 = AI 멘트 → 아이 반응 → 분석/피드백 → 다음 턴)

#### C-1. 인트로(고정)
1. AI가 분위기 조성(첫 멘트)
   - 예: “지후야 안녕! 오늘은 친구랑 장난감 이야기 해볼까?”
2. 아이 반응 유도
   - 아이가 말하면 “좋아! 시작해보자!”로 연결

---

#### C-2. 미션 턴 (MVP 시나리오 예시: **거절하기**)

##### Turn 1: 상황 제시
- AI: “나 그 인형 가지고 놀고 싶은데, 나한테 줄 수 있어?”
- 화면에 간단 텍스트 표시(이해 도움)

##### Turn 2: 아이 반응 입력(음성/침묵)
- 시스템 측정 항목(가벼운 분석)
  - **침묵 시간**: 3초 이상 → “막힘” 판단
  - **음량**: RMS 기반 작음/보통/큼
  - **발화 텍스트(STT)**: “안돼/싫어/다음에/미안” 등 키워드 중심
  - **표정(선택)**: 웃음/무표정/찡그림 등 단순 분류

##### Turn 3: 즉시 피드백 분기(상태 머신)

- (A) **정중한 거절 성공**
  - 조건 예: `미안/다음에/지금은` 등 완곡 표현 포함 + 음량 과하지 않음
  - AI: “좋아! 그렇게 말하니까 내 마음이 괜찮아!”
  - 마음 온도계: **+20**
  - 다음 턴으로 이동

- (B) **거친 거절(재시도 유도)**
  - 조건 예: `싫어/안돼!` + 음량 큼
  - AI: (슬픈 표정 연출) “그렇게 말하니까 마음이 조금 아파…”
  - 마음 온도계: **-15**
  - “마법의 단어 카드” 자동 등장  
    - “미안, 지금은 안돼”  
    - “다음에 같이 하자”
  - AI: “이 중 하나로 다시 말해볼래?” → **재시도 턴 반복**

- (C) **침묵/머뭇거림(힌트 제공)**
  - 조건: 3초 이상 발화 없음
  - AI: “괜찮아! 어려울 수 있어. 이렇게 말해볼까?”
  - 마음 온도계: 변화 없음(또는 +5)
  - 힌트 카드 노출 → 아이가 따라 말하면 성공 처리

---

### D. 마무리 플로우 (보상 + 복습)

#### D-1. 성공 처리
1. 미션 성공 시
   - AI: “하이파이브!” + 간단 애니메이션
   - 배지 지급(로컬/DB 저장)
     - 예: `정중한 거절 배지`
2. 핵심 문장 복습 UI(고정)
   - “오늘의 마법 문장”
     - “미안, 지금은 안돼. 다음에 같이 하자!”
   - 버튼: `한 번 더 말해보기`(선택)

---

### E. 부모 리포트 플로우 (놀이 종료 후 자동)

#### E-1. 결과 생성
- 놀이 종료 → “부모 리포트 생성 중…”
- 서버에서 세션 로그 요약
  - 성공/실패 횟수
  - 침묵 횟수
  - 음량 평균(과격 여부 지표)
  - 사용 문장(키워드 기반)

#### E-2. 리포트 화면(부모용) — MVP 구성
- 오늘의 연습: 거절하기
- 핵심 지표(3개)
  - **재시도 횟수**
  - **침묵 횟수**
  - **정중 표현 사용 여부(0/1 또는 %)**
- 한 줄 코멘트(템플릿)
  - “오늘은 처음에 목소리가 컸지만, 힌트 후 정중한 문장을 사용했어요.”
- 부모 가이드 1개
  - “저녁에 ‘친구가 빌려달라면 뭐라고 할까?’를 1번만 물어봐 주세요.”

> (카톡 전송은 3주 MVP 기준: “리포트 페이지 제공”으로 대체 가능)

## 4. 기대 효과 및 고도화 계획

### 기대 효과
- 아이는 실생활에서 적용하기 어려운 사회적 대화(인사/거절/감정 표현)를 **안전하게 반복 연습**
- 실수해도 혼나거나 관계가 틀어질 위험이 없어 **말하기 두려움 감소 + 자기표현 자신감 향상**
- 즉각적인 반응과 시각 피드백으로 **내 말이 상대에게 주는 영향 인식**
- 부모는 감이 아닌 **상황·행동 기반 데이터**로 아이를 이해하고 지도 가능
- 놀이 후 가이드가 실제 부모–아이 대화로 이어져 **가정 내 소통의 질 향상**

### 향후 계획
- 연령·발달 단계에 따른 **난이도/콘텐츠 확장**
- 반복 사용 데이터를 바탕으로 **맞춤형 놀이 추천**
- 결과와 연계된 **오프라인 대화 미션 제공**
- 유치원·어린이집 활용을 위한 **교사 관찰/피드백 모드 도입**
- 장기적으로 사회성 발달이 필요한 아이들을 위한 **보조 학습 도구로 확장**
